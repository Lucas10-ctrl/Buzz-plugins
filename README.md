# Lucas's Buzz plugins

Plugins for the Buzz desktop app (0.7 preview). Each folder is one plugin.

| Plugin | What it does |
| --- | --- |
| [agent-skills](agent-skills) | Gives each agent its own skills: reusable instructions it loads when a task matches. Adds a Skills tab to every agent's settings. |

## Install a plugin

1. Open Buzz → Settings → Plugins → Manage plugins.
2. Choose **Load from folder** and pick a plugin folder (or this whole folder to see them all).
3. Install it, then reload the same folder later to update it.
