# Page Builder

A visual page builder inside Buzz. Edit pages section by section, clone a website, keep a shared section library, and export to Shopify or Vercel.

Works on macOS (Apple Silicon and Intel), Linux x64 and Windows x64. Preview, unsigned.

## Install

In Buzz: **Settings → Plugins → Manage plugins → import from a Git or GitHub repository** → `Lucas10-ctrl/Buzz-plugins`, branch `main` → pick **Page Builder** → install.

The first time you open it, it downloads its runtime from this repo's [releases](https://github.com/Lucas10-ctrl/Buzz-plugins/releases) (about 130 MB, once per computer, shared by all the editor plugins) and checks it against the fingerprints in `manifest.json`. After that it opens straight away.

Don't install it alongside **All Editors**: they add the same agent tools, and Buzz refuses the second one.

## Details

- Plugin id: `lucas.page-builder`
- Agent tools: `buzz_pages` and `buzz_brand`.
- Saved work: Buzz's data folder → `editor-workspaces/`, shared with the other editor plugins.
- Runtime cache: `~/.local/share/buzz-editors/` (Linux), `~/Library/Application Support/buzz-editors/` (macOS), `%LOCALAPPDATA%\buzz-editors\` (Windows). Safe to delete; it downloads again.
- Website cloning on Linux needs GStreamer's good plugins (`sudo pacman -S --needed gst-plugins-good` on Arch).
